# AI Tools

AI assistants (chat models, coding assistants, literature-search tools) can speed up research,
but they must be used responsibly.

## Guidelines

- **You are responsible for everything you submit**: code, text, and figures. Check AI output
  carefully; it can be confidently wrong, including invented citations.
- **Protect data and code.** Don't paste unpublished results, private repositories, student
  records, data under a data-use agreement, or reviewer materials into tools that aren't approved
  for that data. Follow UC Davis guidance on generative AI and data security.
- **Peer review is confidential.** Do not upload manuscripts you are reviewing to AI tools.
- **Disclose** AI use where journals or the university require it.
- **Learn the fundamentals.** Use AI to help you learn, not to skip learning, especially early in
  your training.

The lab **encourages** using AI tools, within these guidelines. When in doubt, ask the PI.

## Useful tools

| Type | Examples |
|------|----------|
| Literature discovery | Research Rabbit, Connected Papers, Elicit, Semantic Scholar |
| General assistants | Claude, ChatGPT, Gemini |
| Coding assistants | Claude Code, GitHub Copilot, Cursor |

Check which tools UC Davis licenses or approves before using them with university data.

# LaTeX and Overleaf for Scientific Writing

**The lab drafts papers in [Overleaf](https://www.overleaf.com)**, an online LaTeX editor that
makes co-writing with the PI and collaborators easy. The journals we publish in (AGU,
Copernicus/EGU, Elsevier, Wiley, IOP) all provide LaTeX templates.

## Getting started

1. Create an Overleaf account with your UC Davis email.
2. Start from the journal's official template (search the Overleaf template gallery).
3. Share the project with the PI and co-authors.

## Tips

- Manage citations with Zotero + Better BibTeX and export a `.bib` file.
- Keep one sentence per line: it makes tracked changes and Git diffs much easier to read.
- Put figures in a `figures/` folder and produce them from scripts so they can be regenerated.
- Use Overleaf comments and track changes for feedback rounds.
